# 要件の書き方の例（見積書）

対象: アプリ 3740（見積書）。番号はアプリの URL `/k/3740/` の数字。

## 帳票

- ボタン名「見積書」。詳細画面で押すと A4 縦の PDF を作り、添付ファイル項目「見積ファイル」に保存する
- 既に見積ファイルがあるときはボタンを出さない
- ファイル名は「見積書-<見積番号>.pdf」
- 押したときは確認してから作成する（`printMode: confirm`）

## 見た目

- 上部: 左に宛名（「御中」付き）、見積金額（合計）、有効期限（見積日の 1 か月後）。右に見積書番号、発行日（見積日）、自社名「株式会社サンプル」、担当者（ユーザー選択項目「担当者」の表示名）、社印（小さな SVG でよい）
- 明細: テーブル「見積明細」の 商品名・数量・単価・金額 を表に。先頭に行番号
- 下部: 左に備考（複数行）、右に 小計・消費税（10%）・合計 の表
- 共通 CSS の既定の見積書の見た目（`pcraft-inv-*`）をベースに、明細の見出し行を濃い色にする

## 更新

- PDF を作ったら、チェックボックス「発行済み」に「済」を入れる

## 聞かれたら答えること

- 一覧 ID や権限は使わない（全員に出す）
- 外部の画像や Web フォントは使わない
