# 計算パターンの検証（お試しアプリと架空の値で評価した結果）

印刷屋 Ver.9 の計算式エンジンで、[計算パターン.md](計算パターン.md) の式の例（`tools/scripts/pattern-cases.mjs`）を、お試しアプリ `formula-sample`（計算式サンプル）に項目を足した架空の値のレコードで、`pcraft_try` / CLI の `try` と同じ評価（ユーザー情報は既定のテストデータ）に通し、期待と突き合わせたもの。`tools/scripts/verify-patterns.mjs`（`npm run gen-patterns`）が作る。手で直さない。
ケース 20、式 88、一致 88、不一致 0。結果は帳票の `${…}` に差し込まれる文字（エンジンの値を文字にしたもの。空は ""）。タイムゾーンは Asia/Tokyo。

## 帳票に差し込む

### 文字列・複数行・金額

- 足した項目: `備考`（MULTI_LINE_TEXT）
- 架空の値: d1 = `{"文字列1":"株式会社<テスト>","備考":"1 行目\n2 行目 & 3","数値1":1234.567}`、d2 = `{"文字列1":"","備考":"","数値1":""}`

| 式 | 結果（レコードごと） | 期待 | 一致 | 注 |
| --- | --- | --- | --- | --- |
| `ESC_HTML(文字列1)` | `["株式会社&lt;テスト&gt;",""]` | `["株式会社&lt;テスト&gt;",""]` | ✔ | 文字列は ESC_HTML（< > & をエスケープ） |
| `REPLACE(ESC_HTML(備考), NEWLINE(), "<br>")` | `["1 行目<br>2 行目 &amp; 3",""]` | `["1 行目<br>2 行目 &amp; 3",""]` | ✔ | 複数行は ESC_HTML してから改行を <br> に |
| `YEN(数値1)` | `["\\1,234.567",""]` | `["\\1,234.567",""]` | ✔ | YEN は \ 付きの桁区切り。印刷屋が帳票の \ を &yen; に置き換えるので ¥ に見える。空は空 |
| `YEN(数値1, 0)` | `["\\1,235",""]` | `["\\1,235",""]` | ✔ | 2 つ目の引数で小数の桁数（四捨五入） |
