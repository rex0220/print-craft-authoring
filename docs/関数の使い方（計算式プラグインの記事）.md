# 計算式の関数の使い方（計算式プラグインの記事の「関数」章の写し）

`formula/doc/qiita_計算式プラグイン.md` の「関数」章を、印刷屋プラグインのライブラリに無い関数の項目（`MEDIAN` `VAR` `VARP` `STDEV` `STDEVP` `UUID` `CRC32`）を外して 2026-10-04 に `tools/scripts/gen-function-list.mjs` が写したもの（手で直さない）。例が多いので、`関数一覧.md` で名前を見つけてからここを検索する。HTML 関連の関数は `帳票関数リファレンス.md` を正とする。

関数は、下記のように「(」を空白を入れずに、記述します。
空白があると、fieldcode として扱われます。

　関数名(パラメータ)

OK: CEIL(数値, 1)
NG: CEIL (数値, 1)


関数一覧

- ABS：　絶対値を返す
    - ABS(fieldcode)
    - 例 ABS(数値)
    - 例 ABS(-1.234) -> 1.234
    - 例 ABS("1.234a") -> ""<br><br>

- ARRAY：　配列
    - ARRAY(fieldcode[,fieldcode[,...]])
    - ARRAY(文字列1,文字列2)<br><br>

- ARRAY_COUNT：　配列数
    - ARRAY_COUNT(fieldcode[,fieldcode[,...]])
    - 例 ARRAY_COUNT(文字列1,文字列2)<br><br>

- ARRAY_DEL：　配列要素を削除
    - ARRAY_DEL(fieldcode[,fieldcode[,...]])
    - 例 ARRAY_DEL(チェックボックス,文字列2)
    - 例 ARRAY_DEL(チェックボックス1,文字列1,チェックボックス2)<br><br>

- ARRAY_EQUALS： ２つの配列のすべての要素が等しいか判定
    - ARRAY_EQUALS(配列,配列)
    - 例 ARRAY_EQUALS(ARRAY(1,2,3),ARRAY(1,2,3)) -> true
    - 例 ARRAY_EQUALS(ARRAY(1,2,3),ARRAY(1,2,3,4)) -> false<br><br>

- ARRAY_EVERY: 配列のすべての要素が特定の条件を満たしているか判定
    - ARRAY_EVERY(項目,変数名[,インデックス],要素式)
    - 例 ARRAY_EVERY(ARRAY(1,2,3),XX,XX>1) -> false
    - 例 ARRAY_EVERY(ARRAY(1,2,3),XX,XX>0) -> true<br><br>

- ARRAY_FIL：　配列の要素を式でフィルタリング
    - ARRAY_FIL(項目,変数名[,インデックス],要素式)
    - 例 ARRAY_FIL(ARRAY(1,2,3),XX,XX>1) -> [2,3]
    - 例 ARRAY_FIL(ARRAY(1,2,3),XX,XX!=2) -> [1,3]
    - 例 ARRAY_FIL(ARRAY("A","B","C"),XX,XX!="A") -> ["B","C"]
    - 例 ARRAY_FIL(ARRAY(1,2,3),XX,idx,idx>1) -> [3]
    - 使用例：[rex0220 計算式プラグイン ARRAY_MAP 関数](https://qiita.com/rex0220/items/2d101f3fbce95c64750a)<br><br>

- ARRAY_FOR：　指定した要素数の配列に変換※最大数 1000
    - ARRAY_FOR(項目[,インデックス],要素式)
    - 例 ARRAY_FOR(3,idx,idx) -> [0,1,2]
    - 例 ARRAY_FOR(3,idx,idx*3) -> [0,3,6]
    - 例 ARRAY_FOR(3,"A") -> ["A","A","A"]
    - 例 ARRAY_FOR(3,idx,"A"&idx) -> ["A1","A2","A3"]<br><br>

- ARRAY_GET：　配列の指定位置(0-,"first","last")の１要素を取得
    - ARRAY_GET(fieldcode,指定位置)
    - 例 ARRAY_GET(チェックボックス1,0)
    - 例 ARRAY_GET(チェックボックス1,"first")
    - 例 ARRAY_GET(チェックボックス1,"last")<br><br>

- ARRAY_DIC：　配列の要素を式で評価し、辞書（ディクショナリー/連想配列）を作成する
    - ARRAY_DIC(配列, 変数名[, インデックス], 式)
    - 例 ARRAY_DIC(ARRAY(1,2,3), vn, DIC(vn, 1)) -> {"1":"1","2":"1","3":"1"}
    - 例 ARRAY_DIC(ARRAY(1,2,3), vn, idx, DIC(vn, idx)) -> {"1":0, "2":1, "3":2}
    - 例 ARRAY_DIC(ARRAY(DIC("A",1),DIC("B",2)), vn, vn) -> {"A":"1","B":"2"}<br><br>

- ARRAY_MAP：　配列の要素を式で変換
    - ARRAY_MAP(項目,変数名[,インデックス],要素式)
    - 例 ARRAY_MAP(ARRAY(1,2,3),XX,XX*3) -> [3,6,9]
    - 例 ARRAY_MAP(ARRAY(1,2,3),XX,"A"&XX) -> ["A1","A2","A3"]
    - 例 ARRAY_MAP(ARRAY("A","B","C"),XX,"A"&XX) -> ["AA","AB","AC"]
    - 例 ARRAY_MAP(ARRAY(1,2,3),XX,idx,XX+idx) -> [1,3,5]
    - 使用例：[rex0220 計算式プラグイン ARRAY_MAP 関数](https://qiita.com/rex0220/items/2d101f3fbce95c64750a)<br><br>


- ARRAY_SOME: 配列内の少なくとも1つの要素が指定された条件を満たしているか判定
    - ARRAY_SOME(項目,変数名[,インデックス],要素式)
    - 例 ARRAY_SOME(ARRAY(1,2,3),XX,XX>1) -> true
    - 例 ARRAY_SOME(ARRAY(1,2,3),XX,XX>0) -> true
    - 例 ARRAY_SOME(ARRAY("A","B","C"),XX,XX="X") -> false<br><br>

- ARRAY_SORT：　配列のソート
    - ARRAY_SORT(fieldcode [,ソート順])
        - ソート順： 1:昇順、0:降順
    - 例 ARRAY_SORT(チェックボックス1)
    - 例 ARRAY_SORT(チェックボックス1,0)<br><br>

- AVE： 平均値
    - AVE(fieldcode[,fieldcode...])
    - ※ 空欄は 0 として件数に数えます（AVE(1,2,3,,0) -> 1.2）。空欄をスキップする MEDIAN, VAR, STDEV 等とは扱いが異なります
    - 例 AVE(数値)
    - 例 AVE(数値, 数値_0, 数値_1)<br><br>

- AVEIF： 条件付き平均値
    - AVEIF(condition,fieldcode[,fieldcode...])
    - 例 AVEIF(文字列=="A", 数値)<br><br>

- CEIL: 切り上げ(ROUNDUP関数と機能は同じ)
    - CEIL(fieldcode) 小数点以下を切り上げ
    - CEIL(fieldcode, 小数点位置)
    - 例 CEIL(数値, 1)<br><br>

- CHOOSE：　指定した数値位置(0から始まる)の値を返す
    - CHOOSE(fieldcode, value0 [,value1 [, value2 [,...]]])
    - 例 CHOOSE(数値, 100, 200, 300)
        - CHOOSE(0, 100, 200, 300) -> 100
        - CHOOSE(1, 100, 200, 300) -> 200
        - CHOOSE(3, 100, 200, 300) -> ""
    - 例 CHOOSE(数値, "ABC", "DEF", "XYZ")
        - CHOOSE(2, "ABC", "DEF", "XYZ") -> "XYZ"<br><br>

- CONCAT： 文字連結
    - CONCAT(fieldcode[,fieldcode...])
    - 例 CONCAT(文字列)
    - 例 CONCAT(文字列, 文字列_0, 文字列_1)<br><br>
    - 例 CONCAT(テーブル文字列, ",")<br><br>

- CONCATIF： 条件付き文字連結
    - CONCATIF(condition,fieldcode[,fieldcode...])
    - 例 CONCATIF(文字列=="A", 文字列_0)<br><br>
    - 例 CONCATIF(テーブル文字列=="A", テーブル文字列_0, ",")<br><br>

- COUNT: 数値カウント
    - COUNT(fieldcode[,fieldcode...])
    - 例 COUNT(数値)<br><br>
    
- COUNTA: 空白以外カウント
    - COUNTA(fieldcode[,fieldcode...])
    - 例 COUNTA(文字列)<br><br>

- COUNTIF: 条件付き数値カウント
    - COUNTIF(condition,fieldcode[,fieldcode...])
    - 例 COUNTIF(文字列=="A", 数値)<br><br>

- CONTAINS: テーブル内項目の値を確認する
    - CONTAINS(fieldcode, 値[,値...])
    - 例 CONTAINS(文字列T, "ABC")
    - 例 CONTAINS(チェックボックスT,"ABC","XYZ")
    - 例 CONTAINS("A","","A") -> true<br><br>

- COUNTROW: サブテーブルの行数
    - COUNTROW(fieldcode)
    - 例 COUNTROW(Table)<br><br>

- DISTINCT：　配列の重複値を排除
    - DISTINCT(fieldcode[,fieldcode[,...]])
    - 例 DISTINCT(文字列1,文字列2)
    - 例 DISTINCT(チェックボックス1,チェックボックス2)<br><br>

- FIRST： 先頭の有効な値
    - FIRST(fieldcode[,fieldcode...])
    - 例 FIRST(文字列)
    - 例 FIRST(数値)<br><br>

- FIRSTIF： 条件付き先頭の有効な値
    - FIRSTIF(condition,fieldcode[,fieldcode...])
    - 例 FIRSTIF(文字列=="A", 文字列)
    - 例 FIRSTIF(文字列=="A", 数値)<br><br>

- FIXED：　数値を桁区切りの文字列に変換
    - FIXED(fieldcode [,小数点以下桁数 [,桁区切り]])
        - 小数点以下桁数（式）： 四捨五入なし（規定値）、数値: 指定位置で四捨五入
        - 桁区切り（式）：　1:桁区切り（規定値）、0: 桁区切りなし
    - 例 FIXED(数値)
        - FIXED(1000)：　-> "1,000"
        - FIXED(1234.567)：　-> "1,234.567"
    - 例 FIXED(数値,1) 
        - FIXED(1234.567,1)：　-> "1,234.6"
    - 例 FIXED(数値,-2) 
        - FIXED(1234.567,-2)：　-> "1,200"
    - 例 FIXED(数値,1,0)
        - FIXED(1234.567,1,0)：　-> "1234.6"<br><br>

- YEN: "￥"マーク付きで、数値を桁区切りの文字列に変換（FIXED 関数の"￥"付き版）
    - YEN(fieldcode [,小数点以下桁数 [,桁区切り]])
    - 例 YEN(1234) -> "￥1,234"
    - 例 YEN(1234.567,2) -> "￥1,234.57"
    - 例 YEN(1234.567,2,0) -> "￥1234.57"<br><br>

- FLOOR: 切り下げ(ROUNDDOWN関数と機能は同じ)
    - FLOOR(fieldcode) 小数点以下を切り下げ
    - FLOOR(fieldcode, 小数点位置)
    - 例 FLOOR(数値, 1)<br><br>

- FSIZE: バイト数を適切な単位（B, KB, MB など）に変換し、カンマ区切り付きでフォーマット
    - FSIZE(数値)
    - 例 FSIZE(5000000) -> "4.8 MB"<br><br>

- IF： 条件
    - IF(condition,fieldcode[,fieldcode])
    - 例 IF(文字列=="A", 数値, 数値1)<br><br>

- IFS： 複数条件
    - IFS(condition,fieldcode[,condition,fieldcode[,fieldcode]][,fieldcode])
    - 例 IFS(文字列=="A", 数値, 文字列1=="B", 数値1)<br><br>

- IN： 値の存在チェック
    - IN(fieldcode,string[,string...])
    - 例 IN(文字列, "ABC","DEF","GHI")
    - 例 NOT(IN(文字列, "AB","CD"))
    - 例 IN(SEL_CODE(ユーザー選択,"array"),"user1")
    - 例 IN("A","","A") -> true
    - 例 IN("A","","B") -> false
    - 例 IN("","","B") -> true<br><br>

- INDEXOF：　配列要素の位置を返す。存在しない場合は -1
    - INDEXOF(配列,値)
    - 例 INDEXOF(ARRAY("A","B","C"),"A") -> 0
    - 例 INDEXOF(ARRAY("A","B","C"),"D") -> -1<br><br>

- INT： 整数
    - INT(fieldcode)
    - 例 INT(数値/2)<br><br>

- INTERSECT：　配列の積集合（両方の配列に存在する値を配列で返す）
    - INTERSECT(fieldcode,fieldcode)
    - 例 INTERSECT(チェックボックス1,チェックボックス2)<br><br>

- ISBLANK: 指定されたパラメータがブランクか判定
    - ISBLANK(fieldcode[,fieldcode...])
    - 例 ISBLANK(文字列)
    - 例 ISBLANK(数値)
    - 例 ISBLANK(数値1,数値2)
    - 例 ISBLANK("","","") -> true<br><br>

- ISNUMBER：　指定した値が数値か判定
    - ISNUMBER(fieldcode[,fieldcode...])
    - 例 ISNUMBER(数値)
        - ISNUMBER(100) -> true
        - ISNUMBER("100A") -> false
        - ISNUMBER("") -> false<br><br>

- LAST： 最後の有効な値
    - LAST(fieldcode[,fieldcode...])
    - 例 LAST(文字列)
    - 例 LAST(数値)<br><br>

- LASTIF： 条件付き最後の有効な値
    - LASTIF(condition,fieldcode[,fieldcode...])
    - 例 LASTIF(文字列=="A", 文字列)
    - 例 LASTIF(文字列=="A", 数値)<br><br>

- MAX： 最大値
    - MAX(fieldcode[,fieldcode...])
    - 例 MAX(数値)
    - 例 MAX(数値, 数値_0, 数値_1)<br><br>

- MAXIF： 条件付き最大値
    - MAXIF(condition,fieldcode[,fieldcode...])
    - 例 MAXIF(文字列=="A", 数値)<br><br>

- MIN： 最小値
    - MIN(fieldcode[,fieldcode...])
    - 例 MIN(数値)
    - 例 MIN(数値, 数値_0, 数値_1)<br><br>

- MINIF： 条件付き最小値
    - MINIF(condition,fieldcode[,fieldcode...])
    - 例 MINIF(文字列=="A", 数値)<br><br>

- MOD: 剰余
    - MOD(fieldcode,fieldcode)
    - 例 MOD(数値1, 3)
    - 例 MOD(10, 3) -> 1<br><br>

- MROUND: 倍数に丸める
    - MROUND(fieldcode, multiple)
    - 例 MROUND(10, 3) -> 9
    - 例 MROUND(-10, -3) -> -9<br><br>

- NVL： 指定されたパラメータで最初の空文字以外の値
    - NVL(fieldcode[,fieldcode...])
    - 例 NVL(数値, 0)
    - 例 NVL(数値, 数値_0, 0)
    - 例 NVL(文字列, "初期値")<br><br>

- PI：　円周率を返す
    - PI()
    - 例 PI() -> 3.14159265358979323846
    - 例 M_SIN(PI()/2) -> 1<br><br>

- PRODUCT： かけ算
    - PRODUCT(fieldcode[,fieldcode...])
    - 例 PRODUCT(数値)
    - 例 PRODUCT(数値, 数値_0, 数値_1)
    - 例 PRODUCT(テーブル数値, テーブル数値_0)<br><br>

- PRODUCTIF： 条件付きかけ算
    - PRODUCTIF(condition,fieldcode[,fieldcode...])
    - 例 PRODUCTIF(文字列=="A", 数値)
    - 例 PRODUCTIF(テーブル文字列=="A", テーブル数値)<br><br>

- RAND：　0以上、1未満の範囲で少数の乱数を返す
    - RAND()
    - 例 RAND()<br><br>

- RANDBETWEEN：　指定した範囲で整数の乱数を返す
    - RANDBETWEEN(最小値,最大値[,配列数])
    - 例 RANDBETWEEN(1, 10)
    - 例 RANDBETWEEN(1,10,10) -> [6,9,6,3,5,3,3,10,9,5]<br><br>

- REVERSE：　配列の反転、文字列の反転
    - REVERSE(fieldcode)
    - 例 REVERSE(チェックボックス)
    - 例 REVERSE(ARRAY("AB","CD","EF")) // -> ARRAY("EF","CD","AB")
    - 例 REVERSE(文字列)
    - 例 REVERSE("ABCDEF") // -> "FEDCBA"<br><br>

- BROUND: 最近接偶数への丸め（銀行丸め）
    - BROUND(fieldcode) 小数点以下を最近接偶数へ丸め
    - BROUND(fieldcode, 小数点位置)
    - 例 BROUND(数値, 1)
    - 例 BROUND(1.25,1) -> 1.2
    - 例 BROUND(1.35,1) -> 1.4
    - 例 BROUND(2.5) -> 2
    - 例 BROUND(3.5) -> 4<br><br>

- ROUND: 四捨五入
    - ROUND(fieldcode) 小数点以下を四捨五入
    - ROUND(fieldcode, 小数点位置)
    - 例 ROUND(数値, 1)<br><br>

- ROUNDDOWN: 切り下げ(FLOOR関数と機能は同じ)
    - ROUNDDOWN(fieldcode) 小数点以下を切り下げ
    - ROUNDDOWN(fieldcode, 小数点位置)
    - 例 ROUNDDOWN(数値, 1)<br><br>

- ROWNO: 処理中のサブテーブル行位置
    - ROWNO(fieldcode)
    - 例 ROWNO(Table)<br><br>

- ROWID: テーブル行id を取得
    - ROWID([テーブル][,指定行])
    - 例 ROWID() -> カレントテーブル・カレント行の id
    - 例 ROWID(テーブル, 0) -> テーブル指定行の id<br><br>

- ROUNDUP: 切り上げ(CEIL関数と機能は同じ)
    - ROUNDUP(fieldcode) 小数点以下を切り上げ
    - ROUNDUP(fieldcode, 小数点位置)
    - 例 ROUNDUP(数値, 1)<br><br>

- SHUFFLE：　配列をランダムに並び変え
    - SHUFFLE(配列)
    - 例 SHUFFLE(ARRAY("A","B","C","D","E"))<br><br>

- SUBTABLE：　サブテーブル指定行(0-)の値
    - SUBTABLE(fieldcode [, 指定行])
    - 例 SUBTABLE(文字列, 0)
    - 例 SUBTABLE(文字列)<br><br>

- SQRT： 平方根
    - SQRT(fieldcode)
    - 例 SQRT(数値)<br><br>

- SUM： 合計
    - SUM(fieldcode[,fieldcode...])
    - 例 SUM(数値)
    - 例 SUM(数値, 数値_0, 数値_1)
    - 例 SUM(テーブル数値, テーブル数値_0, テーブル数値_1)
    - 例 SUM(ARRAY(1,2,3),4,5)<br><br>

- SUMIF： 条件付き合計
    - SUMIF(condition,fieldcode[,fieldcode...])
    - 例 SUMIF(文字列=="A", 数値)
    - 例 SUMIF(テーブル文字列=="A", テーブル数値)<br><br>

- SWITCH： 複数条件で指定値を返す

    - 例 SWITCH(文字列,"A", 数値1, "B", 数値2, 数値3)<br><br>

- WHICH：　指定したユーザーが各条件（ユーザー選択・組織・グループ等）に含まれているかを順に判定し、一致した最初の値を返す
     ユーザーコードを省略した場合、ログインユーザー
     条件はユーザー選択フィールド、OUSERS/GUSERSなど配列で返すものに対応。
    - WHICH([ユーザーコード], 条件1, 値1, ..., デフォルト値)
    - 例 WHICH("user_001", 更新者, 1, ユーザー選択, 1, OUSERS("sales"), 1,
     OUSERS("dev"), 0, GUSERS("everyone"), 1, 1)
    - 例 WHICH(ユーザー選択, 100, 0)
     -> // ログインユーザーがユーザー選択に含まれていれば100, 含まれていなければ0<br><br>

- TARRAY：　テーブル内項目の配列化

    - 例 TARRAY(文字列1,文字列2)<br><br>

- TARRAYIF：　条件付きテーブル内項目の配列化
    - TARRAYIF(condition,fieldcode [,fieldcode [,...]])
    - 例 TARRAYIF(文字列=="A",文字列1,文字列2)<br><br>

- TDS：　テーブル内項目の配列化（配列の重複値を排除）
    - TDS(fieldcode [,fieldcode [,...]])
    - 例 TDS(文字列1,文字列2)<br><br>

    - TDSIF(condition,fieldcode [,fieldcode [,...]])

- TDUPCK：　テーブル重複値チェック テーブル内項目を指定して重複値がある場合、true を返す
    - TDUPCK(fieldcode[,flag])
        - flag: 空文字を除外 0:除外しない 1:除外する
    - 例 TDUPCK(文字列)
        - TDUPCK(文字列)  -> true 重複値がある場合, false 重複値が無い場合
    - 例 TDUPCK(文字列,1)  ※空文字を除外
        - TDUPCK(文字列,1) -> false ※(文字列が"A","","")<br><br>

- TR_AVE：　同一行のテーブル内項目で平均値
    - TR_AVE(fieldcode[,fieldcode...])

- TR_COUNT：　同一行のテーブル内項目で数値をカウント

- TR_MAX：　同一行のテーブル内項目で最大値

- TR_MIN：　同一行のテーブル内項目で最小値

## 日付関数

## ディクショナリー関数

- DIC: ディクショナリー作成 (指定された key と value で、Dictionaryを作成)
    - DIC([key,value][,...])
    - 例 DIC() -> {}
    - 例 DIC("A",1) -> {"A":1}
    - 例 DIC("A",1,"B",2) -> {"A":1,"B":2}
    - 例 DIC("A",1,"B",ARRAY(1,2)) -> {"A":1,"B":[1,2]}
    - 例 DIC("A",1,"B",DIC("B1",2,"B2",3)) -> {"A":1,"B":{"B1":2,"B2":3}}<br><br>

- DIC_ASSIGN: 指定された Dictionary で、新たな Dictionaryを作成
    - DIC_ASSIGN(dictionary[,...])
    - 例 DIC_ASSIGN(DIC("A",1)) -> {"A":1}
    - 例 DIC_ASSIGN(DIC("A",1),DIC("B",2)) -> {"A":1,"B":2}
    - 例 DIC_ASSIGN(DIC("A",1),DIC("A",2,"B",ARRAY(1,2))) -> {"A":2,"B":[1,2]}<br><br>

- DIC_COUNT: 指定された Dictionary の要素数
    - DIC_COUNT(dictionary)
    - 例 DIC_COUNT(DIC("A",1)) -> 1
    - 例 DIC_COUNT(DIC("A",1,"B",2)) -> 2<br><br>

- DIC_DEL: Dictionary から指定された要素を削除
    - DIC_DEL(dictionary,key[,key...])
    - 例 DIC_DEL(DIC("A",1),"A") -> {}
    - 例 DIC_DEL(DIC("A",1,"B",2,"C",3),"A","B") -> {"C":3}
    - 例 DIC_DEL(DIC("A",1,"B",2,"C",3),ARRAY("A","B")) -> {"C":3}<br><br>

- DIC_EXISTS: Dictionary に指定されたキーがあるかチェック
    - DIC_EXISTS(dictionary,key)
    - 例 DIC_EXISTS(DIC("A",1),"A") -> true
    - 例 DIC_EXISTS(DIC("A",1,"B",2),"C") -> false<br><br>

- DIC_ITEM: Dictionary に指定されたキーの値を取得。値指定時は値をセット
    - DIC_ITEM(dictionary,key[,value])
    - 例 DIC_ITEM(DIC("A",1),"A") -> 1
    - 例 DIC_ITEM(DIC("A",1),"B") -> ""
    - 例 DIC_ITEM(DIC("A",1),"A","2") -> {"A":2}
    - 例 DIC_ITEM(DIC("A",1),"B",2) -> {"A":1,"B":2}<br><br>

- DIC_KEYS: 指定された Dictionary のキーを配列で取得
    - DIC_KEYS(dictionary)
    - 例 DIC_KEYS(DIC("A",1)) -> ["A"]
    - 例 DIC_KEYS(DIC("A",1,"B",2)) -> ["A","B"]<br><br>

- DIC_MAP: Dictionary の要素を式で配列に変換
    - DIC_MAP(dictionary,key,value[,index],formula)
    - 例 DIC_MAP(DIC("A",1,"B",2),key,val,key&":"&val) -> ["A:1","B:2"]
    - 例 DIC_MAP(DIC("A",1,"B",2),key,val,val) -> [1,2]
    - 例 DIC_MAP(DIC("A",1,"B",2),key,val,idx,key&":"&(val+idx)) -> ["A:1","B:3"]<br><br>

            - sortOrder: 表示優先度
            - #xxxx: カスタマイズ項目のコード
            - orgs: 所属組織
            - groups: 所属グループ
            - setData: ユーザー選択項目用データ
        - separator：　区切り文字
- 例
    -  UINFO() -> ["code1",...]
    - UINFO("code1") -> [{"id":"1","code":"code1",...}]
    - UINFO("code1,code2") -> [{"id":"1","code":"code1",...},{"id":"2","code":"code2",...}]
    - UINFO("code1","name") -> ["name1"]
    - UINFO("code1","name,birthDate") -> ["name1,2000-01-01"]
    - UINFO("code1,code2","name,birthDate") -> ["name1,2000-01-01","name2,2000-01-01"]
    - UINFO("code1,code2","name,birthDate","+") -> ["name1+2000-01-01","name2+2000-01-01"]
    - UINFO("code1","orgs") -> ["org1,org2"]
    - UINFO("code1","groups") -> ["group1,group2"]
    - UINFO("code1","setData") -> [{"code":"code1","name":"name1"}]<br><br>

    - OINFO("code1","setData") -> [{"code":"code1","name":"name1"}]<br><br>

- OUSERS：　指定した組織に所属するユーザーコードの一覧を返す

## 数学関数 M_...

- M_LOG：常用対数
    - M_LOG(数値 [,底])
        - 数値の常用対数（デフォルト底は10）を計算
        - 例: M_LOG(10) -> 1
        - 例: M_LOG(100) -> 2
        - 例: M_LOG(27, 3) -> 3<br><br>

- M_EXP：指数関数（eの累乗）
    - M_EXP(数値)
        - e（自然対数の底）の数値乗を計算
        - 例: M_EXP(1) -> 2.718281828459045<br><br>

- M_LN：自然対数
    - M_LN(数値)
        - 数値の自然対数（デフォルト底はe）を計算
        - 例: M_LN(10) -> 2.302585092994046
        - 例: M_LN(100) -> 4.605170185988091<br><br>

- M_POW：べき乗
    - M_POW(底, 指数)

- M_ASIN：逆正弦

## 財務関連の関数 R_...

- R_RRI：定期投資収益率（年利率）
    - R_RRI(n, pv, fv)
        - n: 期間（年数など）
        - pv: 現在価値（元本）
        - fv: 将来価値（満期時の金額）
        - return: 年利率
    - 例: R_RRI(5, 100000, 200000) -> 0.1486983549970350068<br><br>

- R_RATE：等額返済の期間利率
    - R_RATE(nper, pmt, pv [,fv, type])
        - nper: 期間（回数）
        - pmt: 各期支払額（通常マイナス）
        - pv: 現在価値
        - fv: 将来価値（省略可, 通常0）
        - type: 期首=1, 期末=0（省略可, 通常0）
        - return: 期間利率
    - 例: R_RATE(36, -30000, 1000000) -> 0.00422066754538318791
    - 例: R_RATE(36, -30000, 1000000, 0, 1) -> 0.0044690238300625143<br><br>

- R_NPER：返済回数（期間）
    - R_NPER(rate, pmt, pv [,fv, type])
        - rate: 各期利率（例: 0.005）
        - pmt: 各期支払額（通常マイナス）
        - pv: 現在価値
        - fv: 将来価値（省略可, 通常0）
        - type: 期首=1, 期末=0（省略可, 通常0）
        - return: 期間（回数）
    - 例: R_NPER(0.004, -30000, 1000000) -> 35.846713726867021404<br><br>

- R_PMT：定額返済額（毎回の支払額）
    - R_PMT(rate, nper, pv [,fv, type])
        - rate: 各期利率（例: 0.005）
        - nper: 期間（回数）
        - pv: 現在価値（元本）
        - fv: 将来価値（省略可, 通常0）
        - type: 期首=1, 期末=0（省略可, 通常0）
        - return: 各期支払額（マイナス値）
    - 例: R_PMT(0.004, 36, 1000000) -> -29881.184143792577868
    - 例: R_PMT(0.004, 36, 1000000, 0, 1) -> -29762.135601387029749<br><br>

- R_IPMT：各期の利息支払額
    - R_IPMT(rate, per, nper, pv [,fv, type])
        - rate: 各期利率
        - per: 何期目か（1〜nper）
        - nper: 期間
        - pv: 現在価値
        - fv: 将来価値（省略可, 通常0）
        - type: 期首=1, 期末=0（省略可, 通常0）
        - return: 利息額（マイナス値）
    - 例: R_IPMT(0.004, 1, 36, 1000000) -> -4000
    - 例: R_IPMT(0.004, 2, 36, 1000000) -> -3896.4752634248296885
    - 例: R_IPMT(0.004, 2, 36, 1000000, 0, 1) -> -3880.951457594451881<br><br>

- R_PPMT：各期の元本返済額
    - R_PPMT(rate, per, nper, pv [,fv, type])
        - rate: 各期利率
        - per: 何期目か（1〜nper）
        - nper: 期間
        - pv: 現在価値
        - fv: 将来価値（省略可, 通常0）
        - type: 期首=1, 期末=0（省略可, 通常0）
        - return: 元本額（マイナス値）
    - 例: R_PPMT(0.004, 1, 36, 1000000) -> -25881.184143792577868
    - 例: R_PPMT(0.004, 1, 36, 1000000, 0, 1) -> -29762.135601387029749<br><br>

- R_FV：将来価値
    - R_FV(rate, nper, pmt [,pv, type])
        - rate: 各期利率
        - nper: 期間
        - pmt: 各期支払額
        - pv: 現在価値（省略可, 通常0）
        - type: 期首=1, 期末=0（省略可, 通常0）
        - return: 将来価値
    - 例: R_FV(0.004, 36, -30000, 0) -> 1159143.2537755538318
    - 例: R_FV(0.03/12, 60, -20000) -> 1292934.2524421926672
    - 例: R_FV(0.05, 100, -10000, 0, 1) -> 27405264.147723725556<br><br>

- R_PV：現在価値
    - R_PV(rate, nper, pmt [,fv, type])
        - rate: 各期利率
        - nper: 期間
        - pmt: 各期支払額
        - fv: 将来価値（省略可, 通常0）
        - type: 期首=1, 期末=0（省略可, 通常0）
        - return: 現在価値
    - 例: R_PV(0.004, 36, -30000) -> 1003976.2766975921388
    - 例: R_PV(0.004, 36, -30000, 0, 1) -> 1007992.1818043825073<br><br>

- R_NPV：正味現在価値（NPV）
    - R_NPV(rate, cashflows)
        - rate: 割引率（小数）
        - cashflows: キャッシュフロー配列（1期目以降）
        - return: 正味現在価値
    - 例: R_NPV(0.05, ARRAY(-100000, 40000, 50000, 60000)) -> 33597.112314313480495
    - 例: R_NPV(0.025, ARRAY(-100000, 40000, 50000, 60000)) -> 41298.609471926323563<br><br>

- R_XNPV：不定期キャッシュフローの正味現在価値（XNPV）
    - R_XNPV(rate, cashflows, dates)
        - rate: 割引率（小数, 例:0.05）
        - cashflows: キャッシュフロー配列（1件以上）
        - dates: 日付配列（YYYY-MM-DD文字列またはUNIX秒。valuesと同数）
        - return: 不定期キャッシュフローの正味現在価値
        - 例: R_XNPV(0.05, ARRAY(-100000, 40000, 50000, 60000), ARRAY("2020-01-01", "2021-01-01", "2022-01-01", "2023-01-01")) → 35258.886438619962132<br><br>

- R_NOMINAL：名目年利率
    - R_NOMINAL(effect_rate, npery)
        - effect_rate: 実効年利率
        - npery: 年間複利回数
        - return: 名目年利率
    - 例: R_NOMINAL(0.0512, 12) -> 0.0500363980482339852
    - 例: R_NOMINAL(0.08, 4) -> 0.07770618763309405<br><br>

- R_EFFECT：実効年利率
    - R_EFFECT(nominal_rate, npery)
        - nominal_rate: 名目年利率
        - npery: 年間複利回数
        - return: 実効年利率
    - 例: R_EFFECT(0.05, 12) -> 0.0511618978817331902
    - 例: R_EFFECT(0.08, 4) -> 0.08243216<br><br>

- R_IRR：内部収益率（IRR）
    - R_IRR(cashflows)
        - cashflows: キャッシュフロー配列（最初は通常マイナス：投資）
        - return: IRR（年利率）
    - 例: R_IRR(ARRAY(-100000, 30000, 40000, 50000)) -> 0.08896339469335016841
    - 例: R_IRR(ARRAY(-100000, 20000, 30000, 40000, 50000)) -> 0.12825726900167427191<br><br>

- R\_MIRR：修正内部収益率（MIRR）
    - R\_MIRR(cashflows, finance\_rate, reinvest\_rate)
        - cashflows: キャッシュフロー配列（最初は通常マイナス：投資）
        - finance\_rate: 資金流出時の借入利率（小数, 例:0.04）
        - reinvest\_rate: 資金流入時の再投資利率（小数, 例:0.05）
        - return: MIRR（年利率）
    - 例: R\_MIRR(ARRAY(-100000, 30000, 40000, 50000), 0.04, 0.05) -> 0.0774327454106084039
    - 例: R\_MIRR(ARRAY(-100000, 20000, 30000, 40000, 50000), 0.04, 0.05) -> 0.1033980089962074405<br><br>

- R_XIRR：不規則期日の内部収益率（XIRR）
    - R_XIRR(cashflows, dates)

        - dates: 日付配列
        - return: XIRR（年利率）
    - 例: R_XIRR(ARRAY(-100000, 30000, 40000, 50000), ARRAY("2020-01-01","2021-01-01","2022-01-01","2023-01-01")) -> 0.08884314992082729167

- R_CUMIPMT：指定期間の累計利息支払額
    - R_CUMIPMT(rate, nper, pv, start_period, end_period [,type])

        - pv: 現在価値
