# 帳票関数リファレンス（印刷屋プラグイン固有の関数と置き換えタグ）

印刷屋プラグイン Ver.6 の帳票（HTML 設定）で使う、印刷屋固有の計算式の関数・置き換えタグ・疑似項目の正本です。一般の関数は `関数一覧.md` と `関数リファレンス（詳細）.md`。
エスケープの列は、印刷屋の計算式ライブラリ（KintoneFormulaPCraft）を実際に動かして確かめた結果です（print-craft の `docs/authoring-plan.md` 11 章）。文書の説明と違うところは実測を正にしています。

## 0. 帳票の評価の流れ（この順で読む）

1. **ボタン表示条件**（HTML 設定 1 行目 `$out` の計算式）が真ならボタンを出す（空なら常に出す）。
2. ボタンを押すと **ファイル名**（2 行目 `$fname` の計算式）を評価し、`.pdf` が無ければ足す。
3. 3 行目以降の有効な行を上から順に処理する: **HTML 欄の `${式}` をレコードの値で置き換える**（エスケープされない）→ 行に計算式があれば、置き換えた HTML を疑似項目 **`$html`** に入れて計算式を評価し、**その結果を行の出力にする**（計算式が無ければ置き換えた HTML が出力）。
4. 出力を連結して DOM に入れる。`class="rex0220-pcraft-page"` の要素が **1 ページ**（用紙の大きさに固定。はみ出た部分は切れる）。
5. ページの中の **置き換えタグ** `#{…}` を処理する: `#{&f(fileKey)}` → 添付ファイルの画像、`#{&q(文字列)}` → QR コードの画像、`#{&p}` / `#{&n}` → ページ番号 / 総ページ数。
6. ページを画像にして PDF にする（html2canvas → jsPDF）。保存先の添付ファイル項目（`filecode`）があれば保存し、更新項目の計算式でレコードを更新する。

**信頼境界の規則（AI が守る）**: 文字列の差し込みは `${ESC_HTML(項目)}`。`${式}` を属性値（`src` / `href` / `style` / `title` など）の中に置かない（`ESC_HTML` は引用符を逃がさない）。`HTML()` / `FVAL()` / `TABLE_HTML()` / `RECS_HTML()` / `FIELDS_HTML()` はレコードの値を**生の HTML として**入れる関数なので、`normalize` が警告し、差分を人が見る。

## 1. 置き換えタグ（HTML の中に書く。属性値の中でも使える）

| タグ | 置き換わるもの | 書く場所 | 備考 |
| --- | --- | --- | --- |
| `#{&f(fileKey)}` | 添付ファイルの画像（data URL）。取れなければ代替画像 | `<img src="#{&f(…)}">`、`style="background-image: url(#{&f(…)})"` | fileKey はレコードの添付ファイル項目の値（`IMGSRC(項目)` が返す）。他のアプリの画像を社印などに使うときは、その環境の fileKey を利用者が調べる（別の環境では無効） |
| `#{&q(文字列)}` | 文字列を QR コードにした画像 | `<img src="#{&q(…)}">` | 文字列にレコードの値を直接つなぐと `)` や `'` で壊れる。`URL()` などで組んだ値を計算式側で作る |
| `#{&p}` / `#{&n}` | ページ番号 / 総ページ数 | テキスト（例 `#{&p} / #{&n}`） | 1 つの `#{…}` の中に両方書ける（`#{&p/&n}` → `1/3`） |

## 2. 疑似項目（計算式の中で項目のように使う）

| 名前 | 意味 | 使える場所 |
| --- | --- | --- |
| `$id` | レコード番号 | 全部 |
| `$revision` | リビジョン | 全部 |
| `$html` | その行の HTML 欄の `${式}` を置き換えた結果 | 3 行目以降の計算式（`REPLACE($html, "##table##", …)` の形で使う） |
| `$rseq` | 一覧帳票（`RECS_HTML`）で処理中のレコードの順番（0 から） | `RECS_HTML` の引数の中（`ARRAY("#", $rseq + 1)`） |
| `$out` / `$fname` | 1 行目・2 行目の行の種類を表すコード（`fieldcode` に書く。計算式の中では使わない） | HTML 設定の 1 行目・2 行目 |

## 3. 関数

列の意味: **エスケープ** = レコードの値が入るときに `<` `>` `&` を実体参照にするか。**Node** = authoring の tools（Node + happy-dom）で評価できるか（`dom` = できる、`kintone-meta` = kintone の情報のスタブで評価、`unsupported` = 評価しない）。

### 3.1 HTML を組む

| 関数 | 書き方 | 返すもの | エスケープ | Node | 説明 |
| --- | --- | --- | --- | --- | --- |
| `TABLE_HTML` | `TABLE_HTML(テーブル, [OPT(…),] 項目または ARRAY(題, 値[, クラス[, 合計の式]]) …)` | `<table class="pcraft-table-table">…</table>` の文字列（`pagination` で複数ページ） | **しない**（セルにレコードの値がそのまま入る） | dom | テーブル項目の各行を表にする。項目は型の書式（桁区切り、単位、日付）で表示。独自の値は `ARRAY("題", 式[, "クラス名"])`。`OPT("type","card")` でカード形式。`ROWNO(テーブル) + 1` で行番号 |
| `RECS_HTML` | `RECS_HTML([OPT(…),] 項目または ARRAY(題, 値[, クラス[, 合計の式]]) …)` | 一覧画面のレコード（最大 100 件、表示順）を表にした文字列 | **しない** | dom（ただし 1 レコードの preview では確認できない） | 一覧帳票（`list: true` のボタン）専用。`$rseq` が順番、`RECS_SUM(項目)` が合計。`OPT("footer","Y")` と `ARRAY` の 4 つ目の引数（合計の式を文字列で）で合計欄。`OPT("type","card")` でカード形式 |
| `FIELDS_HTML` | `FIELDS_HTML(項目[, …][, OPT("pref","pcraft-card-","itemClass","item","lClass","label","vClass","value","hideLabels","N")])` | ラベルと値を並べたカード形式の文字列 | **しない** | dom | 項目を縦に並べる。`TABLE_HTML` の `ARRAY` の値に入れると「テーブル + カード」 |
| `PAGE_HTML` | `PAGE_HTML(TAG(…)[, …])` | `<div class="rex0220-pcraft-page">…</div>` の文字列 | 子に従う（`TAG` の文字列の子は `<` `>` だけ） | dom | 計算式だけで 1 ページを組む形。HTML テンプレートを使う形では不要 |
| `TAGS_HTML` | `TAGS_HTML(TAG(…)[, …])` | 複数の `TAG` を連結した文字列 | 子に従う | dom | `TAGS_HTML(ARRAY_MAP(ARRAY(…), x, PAGE_HTML(…)))` で複数ページ |
| `TAG` | `TAG(タグ名[, ATTR(…), STYLE(…), BATTR(…), 子 …])` | 要素（オブジェクト。`PAGE_HTML` / `TAGS_HTML` が文字列にする） | 文字列の子は **`<` `>` だけ**（`&` と引用符はそのまま） | dom | 子は文字列・`TAG` / `VTAG`・`HTML()`・配列 |
| `VTAG` | `VTAG(タグ名[, ATTR(…), STYLE(…)])` | 中身の無い要素（`br` / `hr` / `img` / `input`） | 属性はしない | dom | `VTAG("img", ATTR("src", IMGSRC(添付ファイル)))` |
| `ATTR` | `ATTR(属性名, 値[, 属性名, 値 …])` | 属性の指定 | **しない**（値の `"` で属性が壊れる） | dom | 値にレコードの項目を入れない（固定の文字列か、`IMGSRC` のような安全な値だけ） |
| `BATTR` | `BATTR(属性名[, …])` | 真偽属性（`checked` など）の指定 | — | dom | |
| `STYLE` | `STYLE(属性名, 値[, …])` または `STYLE("color:red; …")` | style 属性の指定 | しない | dom | 値にレコードの項目を入れない |
| `HTML` | `HTML(文字列[, …])` | 「生の HTML」の印 | **しない**（印そのもの） | dom | `TAG("span", HTML(FVAL(備考)))` のように、`TAG` の子に HTML をそのまま入れるとき。信頼できる値だけ |
| `OPT` | `OPT("キー", "値"[, "キー", "値" …])` | オプション（`TABLE_HTML` / `RECS_HTML` / `FIELDS_HTML` の引数） | — | dom | キーは 3.4 |

### 3.2 値の整形

| 関数 | 書き方 | 返すもの | エスケープ | Node | 説明 |
| --- | --- | --- | --- | --- | --- |
| `ESC_HTML` | `ESC_HTML(項目または文字列)` | `&` `<` `>` を実体参照にした文字列 | **`&` `<` `>` だけ**（`"` `'` はしない） | dom | テキストの差し込みの基本形 `${ESC_HTML(項目)}`。属性値には使えない。複数行の項目は `REPLACE(ESC_HTML(備考), "\n", "<br>")` |
| `UNESC_HTML` | `UNESC_HTML(文字列)` | 実体参照を文字に戻した文字列 | 戻す | dom | リッチエディターの値などに。帳票では通常使わない |
| `FVAL` | `FVAL(項目)` | 項目の型の書式で整えた文字列（桁区切り、単位、日時の形。複数行は改行を `<br>` に） | **しない**（タグも改行の `<br>` もそのまま） | dom | 金額・日付の表示に。文字列項目に使うと生の HTML になる |
| `IMGSRC` | `IMGSRC(添付ファイル項目[, 位置[, "img"]])` | `#{&f(fileKey)}`（`"img"` なら `<img src="#{&f(…)}">`） | — | dom | 位置は 0 から、`-1` は最後。`TABLE_HTML` の `ARRAY("画像", IMGSRC(添付ファイル, 0, "img"), "value-image")` |
| `FILE` | `FILE(添付ファイル項目[, "name" \| "key" \| "type" \| "size"[, 位置]])` | 添付ファイルの情報（配列または 1 つ） | — | dom | `FILE(項目, "key", 0)` で fileKey |
| `FSIZE` | `FSIZE(バイト数[, 単位[, 小数の桁]])` | `"4.8 MB"` のような文字列 | — | dom | |
| `URL` | `URL(プロトコル, パス)` | `"https://…"` | **しない** | dom | QR の文字列などに。レコードの値をつなぐときはエンコード（`ENCODE_URI`）する |
| `ADD_TAGS` | `ADD_TAGS(複数行の文字列)` | 行ごとに `<div>`、`- ` で始まれば `<ul><li>` にした HTML | **しない** | dom | 複数行の文字列を HTML に。値はエスケープされない |
| `STRIP_TAGS` | `STRIP_TAGS(リッチエディター項目)` | タグを除いた文字列 | タグを除く | dom | リッチエディターの値をテキストに |
| `HTML_TAGS` | `HTML_TAGS(HTML 文字列)` | HTML を `TAG(…)` の形に変換した計算式の文字列 | — | dom | 設定を書くときの補助。帳票の計算式では使わない |

### 3.3 一覧帳票（`RECS_HTML` と組み合わせる）

| 関数 | 書き方 | 返すもの | エスケープ | Node | 説明 |
| --- | --- | --- | --- | --- | --- |
| `RECS_SUM` | `RECS_SUM(項目)` | 一覧のレコードの項目の合計 | — | dom（1 レコードの preview では確認できない） | `ARRAY("金額", YEN(金額), "value-right", "YEN(RECS_SUM(金額))")` の 4 つ目（合計の式は文字列で渡す） |
| `RECS_MAP` | `RECS_MAP([変数名,] 式)` | 一覧のレコードごとに式を評価した配列 | — | dom | `RECS_MAP(idx, 文字列 & idx)` |

### 3.4 `OPT` のキー（`TABLE_HTML` / `RECS_HTML` / `FIELDS_HTML`）

| キー | 値 | 対象 | 意味 |
| --- | --- | --- | --- |
| `pref` | class 名の前置き（既定 `pcraft-table-` / `pcraft-card-`） | 3 つ | 生成する要素の class（`<pref>table`、`<pref>th-label`、`<pref>td-value`、`<pref>row` …）。共通 CSS の既定は `pcraft-table-*`（table）、`pcraft-card-*`（card）、`pcraft-inv-item-*`（invoice）に合わせてある |
| `thClass` / `tdClass` | class 名 | TABLE / RECS | 見出し / 値のセルに足す class |
| `itemClass` / `lClass` / `vClass` | class 名 | 3 つ | カード形式の項目 / ラベル / 値の class |
| `title` | 文字列 | TABLE / RECS | 表の題（ページの先頭） |
| `pagination` | `"Y"` / `"N"` | TABLE / RECS | `"Y"` で `perPage` 行ごとにページ（`rex0220-pcraft-page`）を分ける |
| `perPage` | 数（文字列。既定 `"20"`） | TABLE / RECS | 1 ページの行数 |
| `maxPages` | 数（既定 `"10"`） | TABLE / RECS | ページ数の上限 |
| `footer` | `"Y"` / `"N"` | RECS | 合計欄を出す（`ARRAY` の 4 つ目の式） |
| `type` | `"card"` | TABLE / RECS | 表でなくカード形式 |
| `hideLabels` | `"Y"` / `"N"` | 3 つ | カード形式でラベルを出さない |
| `filter` | `"1"` | TABLE / RECS | 行の絞り込み（文書の例のまま） |

`ARRAY(題, 値[, クラス名[, 合計の式]])`: 列の題、セルの値（式）、セルに足す class、合計欄の式（文字列で。`RECS_HTML` の `footer`）。値に HTML 文字列を直接書く（`"<span class='x'>" & 値 & "</span>"`）のは生の HTML になるので避け、`TAG` か class で装飾する。

## 4. エスケープの実測（Ver.6 のライブラリ。authoring-plan.md 11 章）

宛名 = `□□□□株式会社 <b>&"'</b>`、備考 = 改行と `<b>` を含む文字列、商品名に `<script>x</script>` を入れたとき:

| 式 | 出力 | 結論 |
| --- | --- | --- |
| `ESC_HTML(宛名)` | `&lt;b&gt;&amp;"'&lt;/b&gt;` | `&` `<` `>` をエスケープ。引用符はしない → テキストには使える。属性値には使えない |
| `TAGS_HTML(TAG("p", 宛名))` | `<p>… &lt;b&gt;&"'&lt;/b&gt;</p>` | `<` `>` だけ。`&` と引用符はそのまま |
| `TAGS_HTML(TAG("p", ATTR("title", 宛名), "x"))` | `title="□□□□株式会社 <b>&"'</b>"` | **エスケープなし**。`"` で属性が壊れる |
| `FVAL(備考)` | `…<b>太字</b><br>…` | 改行は `<br>`。タグはそのまま（生の HTML） |
| `ESC_HTML(FVAL(備考))` | `&lt;b&gt;太字&lt;/b&gt;&lt;br&gt;` | `<br>` も潰れる → 複数行は `REPLACE(ESC_HTML(備考), "\n", "<br>")` |
| `TABLE_HTML(見積明細, …, 商品名)` | `<td …>… <script>x</script></td>` | **セルの値はエスケープされない** |
| HTML テンプレートの `${宛名}` | `<b>&"'</b>` がそのまま | 生の差し込み |

## 5. 複数ページ

- **テーブルの行で分ける**: `TABLE_HTML(テーブル, OPT("pagination","Y","perPage","20"), …)`。各ページが `rex0220-pcraft-page` になる。ページの外側（見出しなど）は HTML テンプレートでは繰り返せないので、繰り返すなら計算式で組む
- **計算式でページを作る**: `TAGS_HTML(ARRAY_MAP(ARRAY("A","B","C"), x, PAGE_HTML(TAG("div", x))))` → 3 ページ。`ARRAY_FOR(n, i, TAG(…))` で行の繰り返し
- ページ番号は `#{&p}` / `#{&n}`（テキストに書く）

## 6. Node（authoring の tools）での評価

- 印刷屋固有の関数は `document` を使うものがあり、tools は happy-dom で評価する（`normalize` の構文チェック、`preview` の HTML 生成）
- `APP_URL`、`LOOKUP_GETID`、`RELATED_GETID` は kintone の情報が要る（tools は `.env` の `KINTONE_BASE_URL`（無ければ固定のダミー `https://example.cybozu.com`）と fields のアプリ番号のスタブで評価する）
- `BUTTON` / `BOPT` / `DIALOG` / `EV_SET` / `CLIPBORD_WRITE` は帳票では使わない（tools は評価しない）
- `RECS_HTML` / `RECS_SUM` / `RECS_MAP` と `$rseq` は一覧のレコードが要るので、1 レコードの `preview` では空か 1 件の結果になる。一覧帳票の見た目は印刷屋で確かめる
- 分類の正本は `tools/functions.json`（`kind`: print-craft / general、`node`: node / dom / kintone-meta / unsupported）
