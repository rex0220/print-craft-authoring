# sample: 五線譜（Ver.9。印刷屋 Ver.9 の計算式の決まりで書いた版）

[`../五線譜/`](../五線譜/)（印刷屋 Ver.8 で作った版）と同じ帳票を、印刷屋 **Ver.9** の計算式エンジンの決まりで書き直したもの（2026-10-20）。ボタン・項目・CSS・記号・出力は同じで、式が短く、検査と描画が軽い。**印刷屋 Ver.9 から**（置換の組の配列の `REPLACERE` を使うので、Ver.8 では動かない）。tools の preview と、印刷屋 Ver.9 の実機の PDF で確かめた（2026-10-20）。

| ファイル | 内容 |
| --- | --- |
| `settings.json` | `normalize` を通した形（派生値あり。封筒の `PluginVersion` は 9）。そのままインポートできる（アプリ番号 4326 は読み替える）。ボタンは「五線譜」「五線譜（ドレミ付き）」「五線譜（移調）」の 3 つ（242 KB） |
| `fields.json` / `record.json` | `../五線譜/` と同じ |

```
npx @rex0220/print-craft-authoring-tools normalize "docs/samples/五線譜（Ver.9）/settings.json" --fields "docs/samples/五線譜（Ver.9）/fields.json" --dry-run
npx @rex0220/print-craft-authoring-tools preview "docs/samples/五線譜（Ver.9）/settings.json" --fields "docs/samples/五線譜（Ver.9）/fields.json" --record "docs/samples/五線譜（Ver.9）/record.json" --out-dir out
```

## Ver.8 の版との違い

| Ver.8 の決まり | Ver.8 の版の回り道 | この版 |
| --- | --- | --- |
| 同じ関数の 101 個目から、ループの中の呼び出しが崩れる | 段ごとに描く部分を `DIC_ITEM(DIC("p", …), "p")` で包む | 包まない（Ver.9 は上限 200,000） |
| ループの変数の 0 が空になる | 位置に 1 万を足して 0 を避ける | 足さない |
| `REPLACERE` は 1 組ずつ | 入れ子（五線の行で 149 回、うち入れ子 61） | 置換の組の配列で 1 回にまとめる（42 回、入れ子 3。flag の違う組だけ入れ子のまま） |
| 計算回数の上限 10 万回 | 長い曲は 400 字句・96 小節で打ち切る | 2,000 字句・500 小節まで（384 小節・9 ページで約 2.4 秒） |

あわせて、タイの正規表現（6 つ）は HTML 欄の定数でなく、式の中に字の定数で書いた。保存の検査（normalize。印刷屋の設定画面の保存も同じ）は空の値で式を評価し、HTML 欄の定数も読めないので、定数から読んだパターンが空の文字になる。空のパターンの `"g"` の置換が長いタイの path を全部の位置に入れ、Ver.8 の版では検査だけで約 1 秒・ヒープ約 2 GB になっていた。この版では 22 ms・162 MB。
