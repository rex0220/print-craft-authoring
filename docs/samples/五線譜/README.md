# sample: 五線譜（ABC 記法の単旋律 → A4 縦の五線譜。通常・ドレミ付き・移調）

ABC 記法で書いた曲（単旋律）から、五線譜の PDF を作る帳票。記号（ト音記号・音符・休符・臨時記号・連桁・タイ・加線）は書体を使わず、計算式が段ごとに作る SVG のパスで描く。実機で確認済み（2026-10-15。印刷屋 **Ver.8**、5 曲 × 3 ボタンのうち 14 本）。tools 2.1.0 以降で検査・プレビューできる。Qiita の記事「AI に ABC 記法の曲から「五線譜」を作らせる」の帳票。

| ファイル | 内容 |
| --- | --- |
| `settings.json` | `normalize` を通した形（派生値あり）。そのままインポートできる（アプリ番号 4326 は読み替える）。ボタンは「五線譜」「五線譜（ドレミ付き）」「五線譜（移調）」の 3 つ（253 KB） |
| `fields.json` | `pcraft-authoring fields --app 4326` の出力（曲名・作詞・作曲・拍子・調・テンポ・ABC記法・歌詞・移調先・権利メモ・楽譜PDF。接続先は `https://example.cybozu.com` に置き換えてある） |
| `record.json` | プレビュー用の見本のレコード（喜びの歌〈交響曲第 9 番より〉。旋律と詩は著作権の保護期間が終わったもの。`record --fields-from` の出力と同じ形） |

```
npx @rex0220/print-craft-authoring-tools normalize docs/samples/五線譜/settings.json --fields docs/samples/五線譜/fields.json --dry-run
npx @rex0220/print-craft-authoring-tools preview docs/samples/五線譜/settings.json --fields docs/samples/五線譜/fields.json --record docs/samples/五線譜/record.json --out-dir out
```

要点:

- 1 つのボタンは帳票の行 2 つ: 「1 ページ目の題と注記」と「五線（全ページ）」。どちらも HTML 欄は、式が `JSON_P($html, 0)` で読む定数の JSON（正規表現・表・記号の SVG）。計算式の欄（20,000 字まで）から長い定数を外に出すため
- 字句ごとの値（種類・長さ・高さ・符尾の向きなど）は、字句を `{印キー}` の並びにし、後ろに表 `§;キー,値;…` を付けて、`REPLACERE(…, "\{([A-Za-z])([^}]*)\}(?=[\s\S]*§[\s\S]*;\1\2,([^;]*);)", "g", "$3")` の 1 回で引く（1 音ずつ `ARRAY_GET` と `IF` で引くと、関数の呼び出しの数の 2 乗で遅くなる）
- 連桁: 長さを字の並び（16 分 1 つに 1 字）にし、小節の頭から 4 字ごとに `/` を入れる正規表現で拍に分ける。形は「まとまりの音の高さの並び」ごとに `DISTINCT` で 1 回だけ計算する。符尾は長く引いて clipPath（連桁の中心線から音符の側）で切り、16 分の 2 本目は同じ線を 9px ずらして間の x だけ残す
- 段ごとに描く部分は `DIC_ITEM(DIC("p", 式), "p")` で包む。エンジンは関数の一覧の順に、1 つの名前につき左から 100 個まで呼び出しを取り出しておき、101 個目からは字のまま残す。字のまま残った呼び出しは、囲む `ARRAY_FOR`・`ARRAY_MAP` などより先に評価されるので、ループの変数（`k`、ループの中の `LET` の変数など）を読むと `getVal FIELD CODE NOT FOUND: k` になる（`RAND` などはループの全回で同じ値）。関係するのは一覧で `ARRAY_FOR` より前の関数（`ARRAY_GET`・`DIC_ITEM`・`DIC`・`ARRAY`・`ARRAY_COUNT`・`RAND` など）。数えるのは 1 つの式の字面で、`DIC` など一覧で前の関数の呼び出しの中は、その関数を評価するときに別に数える
- 長い曲は 96 小節・400 字句（音符・休符・小節線）で打ち切り、注記を出す。そのときの評価回数は 3.4〜3.8 万回
- 移調: 調号の数の差から移す音名の数と半音の数を出し、近い方（半音 6 つまで）に移す。音の平均が五線の外に出るときは真ん中に近い方。段は実行時に作る小さな表で移し、書いた臨時記号は音名ごとのずれの表で書き直す
- 範囲: 単旋律、ト音記号、2/4・3/4・4/4、全音符〜16 分音符、付点、休符、♯♭♮（ダブルも）、調号、タイ、加線、拍ごとの連桁、歌詞（3 番まで）。和音・スラー・強弱・反復記号（ふつうの小節線で描く）・3 連符は描かない
