# 印刷屋プラグインで使える計算式の関数一覧

印刷屋プラグイン Ver.6 の計算式ライブラリ（KintoneFormulaPCraft）が持つ **243 関数**の一覧。説明はライブラリ自身の説明表（設定画面の関数入力支援の文言）から、分類は計算式プラグインの Qiita 記事「関数」章の見出しに合わせて、`tools/scripts/gen-function-list.mjs` が 2026-10-04 に生成した（手で直さない。ライブラリの SHA-256 8a5f78f78f51）。

- 書式は `NAME(引数の形)` と説明と例。引数の形の `[...]` は省略可
- **★ 印刷屋固有**（HTML 関連）の関数は、エスケープの扱いと使い方を `帳票関数リファレンス.md` で確かめる
- **✕ 帳票では使わない**（ボタン・dialog・クリップボード・イベントの関数。authoring の tools は評価しない）
- 例が多い説明は `関数の使い方（計算式プラグインの記事）.md`、1 関数ずつの詳しい説明は `関数リファレンス（詳細）.md`（印刷屋固有と TP* / R_* / M_* は無い）を検索して読む
- **計算式プラグインにあって印刷屋に無い関数**（使えない）: `MEDIAN` `VAR` `VARP` `STDEV` `STDEVP` `UUID` `CRC32`

## 基本関数（数値・集計・配列・条件）

- **ABS**(項目): 絶対値を返す
    - 例 `ABS(数値)`
    - 例 `ABS(-1.234) -> 1.234`
    - 例 `ABS("1.234a") -> ""`
- **ARRAY**(項目[,...]): 指定された値を配列にする
    - 例 `ARRAY()`
    - 例 `ARRAY(数値1,数値2)`
    - 例 `ARRAY(チェックボックス1,チェックボックス2)`
    - 例 `ARRAY("A","B") -> ["A","B"]`
    - 例 `ARRAY("A","B",ARRAY("C","D")) -> ["A","B","C","D"]`
- **ARRAY_COUNT**(項目[,...]): 配列数
    - 例 `ARRAY_COUNT(チェックボックス)`
    - 例 `ARRAY_COUNT(SEL_CODE(ユーザー選択,"array"))`
    - 例 `ARRAY_COUNT(ARRAY("A","B")) -> 2`
- **ARRAY_DEL**(項目,項目[,...]): 配列要素を削除
    - 例 `ARRAY_DEL(チェックボックス,"sample1")`
    - 例 `ARRAY_DEL(チェックボックス1,チェックボックス2)`
    - 例 `ARRAY_DEL(ARRAY("A","B"),"A") -> ["B"]`
- **ARRAY_DIC**(配列,変数名[,インデックス],式): 配列をループし、各要素で式を評価し、ディクショナリー(連想配列)を作成します。 式は通常 DIC(キー, 値) の形式を返します。
    - 例 `ARRAY_DIC(ARRAY(1,2,3), vn, DIC(vn, 1)) -> {"1":1, "2":1, "3":1}`
    - 例 `ARRAY_DIC(ARRAY(1,2,3), vn, idx, DIC(vn, idx)) -> {"1":0, "2":1, "3":2}`
    - 例 `ARRAY_DIC(ARRAY(DIC("A",1),DIC("B",2)), vn, vn) -> {"A":1, "B":2}`
- **ARRAY_EQUALS**(項目,項目): ２つの配列のすべての要素が等しいか判定
    - 例 `ARRAY_EQUALS(ARRAY(1,2,3),ARRAY(1,2,3)) -> true`
    - 例 `ARRAY_EQUALS(ARRAY(1,2,3),ARRAY(1,2,3,4)) -> false`
    - 例 `ARRAY_EQUALS(ARRAY("A","B","C"),ARRAY("A","B","C")) -> true`
    - 例 `ARRAY_EQUALS(ARRAY(1,2,3),ARRAY("A","B","C")) -> false`
- **ARRAY_EVERY**(項目,変数名[,インデックス],要素式): 配列のすべての要素が特定の条件を満たしているか判定
    - 例 `ARRAY_EVERY(ARRAY(1,2,3),XX,XX>1) -> false`
    - 例 `ARRAY_EVERY(ARRAY(1,2,3),XX,XX>0) -> true`
    - 例 `ARRAY_EVERY(ARRAY("A","B","C"),XX,XX!="X") -> true`
    - 例 `ARRAY_EVERY(ARRAY(1,2,3),XX,idx,idx>1) -> false`
- **ARRAY_FIL**(項目,変数名[,インデックス],要素式): 配列の要素を式でフィルタリング
    - 例 `ARRAY_FIL(ARRAY(1,2,3),XX,XX>1) -> [2,3]`
    - 例 `ARRAY_FIL(ARRAY(1,2,3),XX,XX!=2) -> [1,3]`
    - 例 `ARRAY_FIL(ARRAY("A","B","C"),XX,XX!="A") -> ["B","C"]`
    - 例 `ARRAY_FIL(ARRAY(1,2,3),XX,idx,idx>1) -> [3]`
- **ARRAY_FOR**(項目[,インデックス],要素式): 指定した要素数の配列に変換※最大数 1000
    - 例 `ARRAY_FOR(3,idx,idx) -> [0,1,2]`
    - 例 `ARRAY_FOR(3,idx,idx*3) -> [0,3,6]`
    - 例 `ARRAY_FOR(3,"A") -> ["A","A","A"]`
    - 例 `ARRAY_FOR(3,idx,"A"&idx) -> ["A1","A2","A3"]`
- **ARRAY_GET**(項目,位置): 配列の指定位置(0-,"first","last")の１要素を取得
    - 例 `ARRAY_GET(チェックボックス,0)`
    - 例 `ARRAY_GET(チェックボックス,数値)`
    - 例 `ARRAY_GET(ARRAY("A","B"),1) -> "B"`
    - 例 `ARRAY_GET(ARRAY("A","B"),"first") -> "A"`
    - 例 `ARRAY_GET(ARRAY("A","B"),"last") -> "B"`
- **ARRAY_MAP**(項目,変数名[,インデックス],要素式): 配列の要素を式で変換
    - 例 `ARRAY_MAP(ARRAY(1,2,3),XX,XX*3) -> [3,6,9]`
    - 例 `ARRAY_MAP(ARRAY(1,2,3),XX,"A"&XX) -> ["A1","A2","A3"]`
    - 例 `ARRAY_MAP(ARRAY("A","B","C"),XX,"A"&XX) -> ["AA","AB","AC"]`
    - 例 `ARRAY_MAP(ARRAY(1,2,3),XX,idx,XX+idx) -> [1,3,5]`
- **ARRAY_SOME**(項目,変数名[,インデックス],要素式): 配列内の少なくとも1つの要素が指定された条件を満たしているか判定
    - 例 `ARRAY_SOME(ARRAY(1,2,3),XX,XX>1) -> true`
    - 例 `ARRAY_SOME(ARRAY(1,2,3),XX,XX>0) -> true`
    - 例 `ARRAY_SOME(ARRAY("A","B","C"),XX,XX="X") -> false`
    - 例 `ARRAY_SOME(ARRAY(1,2,3),XX,idx,idx>1) -> true`
- **ARRAY_SORT**(項目[,sort]): 配列のソート 1:昇順, 0:降順
    - 例 `ARRAY_SORT(チェックボックス)`
    - 例 `ARRAY_SORT(チェックボックス,0)`
    - 例 `ARRAY_SORT(ARRAY("A","X","B")) -> ["A","B","X"]`
    - 例 `ARRAY_SORT(ARRAY("A","X","B"),0) -> ["X","B","A"]`
- **AVE**(テーブル内項目[,...]): テーブル内項目の平均値|指定された項目の平均値
    - 例 `AVE(数値T)`
    - 例 `AVE(数値1,数値2,数値3)`
    - 例 `AVE(1,2,3) -> 2`
    - 例 `AVE(1,2,3,,0) -> 1.2`
- **AVEIF**(条件,テーブル内項目[,...]): テーブル内項目の条件付き平均値
    - 例 `AVEIF(ドロップダウンT="sample1", 数値T)`
    - 例 `AVEIF(IN(ドロップダウンT,"A","B"), 数値T)`
- **BROUND**(項目[,小数点位置]): 最近接偶数への丸め（銀行丸め） 小数点位置を省略した場合は0（整数）になります。
    - 例 `BROUND(数値,1)`
    - 例 `BROUND(1.25,1) -> 1.2`
    - 例 `BROUND(1.35,1) -> 1.4`
    - 例 `BROUND(2.5) -> 2`

    - 例 `CEIL(1.23456,4) -> 1.2346`

    - 例 `CHOOSE(数値, "A", "B", "C")`
    - 例 `CHOOSE(0, 100, 200, 300) -> 100`

    - 例 `CHOOSE(4, "A", "B", "C") -> ""`
- **CONCAT**(テーブル内項目[,...]): テーブル内項目の文字連結|指定された項目の文字連結

    - 例 `CONCAT(文字列T,NEWLINE())`
    - 例 `CONCAT(文字列1,文字列2)`

    - 例 `CONCATIF(ドロップダウンT="sample1", 文字列T)`

- **CONTAINS**(項目,項目[,...]): テーブル内項目の値を確認する
    - 例 `CONTAINS(文字列T, "ABC")`
    - 例 `CONTAINS(チェックボックスT,"ABC","XYZ")`
    - 例 `NOT(CONTAINS(文字列T, "AB","CD"))`
    - 例 `CONTAINS(SEL_CODE(ユーザー選択T,"array"),"user1")`

    - 例 `CONTAINS("A","","B") -> false`
    - 例 `CONTAINS("","","B") -> true`
- **COUNT**(テーブル内項目[,...]): テーブル項目の数値カウント|指定された項目で数値カウント
    - 例 `COUNT(数値T)`
    - 例 `COUNT(数値1,数値2,数値3)`

- ★ **FSIZE**(bytes[,unit[,decimals]]): バイト数を適切な単位（B, KB, MB など）に変換し、カンマ区切り付きでフォーマット bytes: バイト数 unit: 変換する単位（"KB", "MB" など）[自動判定] decimals: 小数点以下の桁数 [1]
