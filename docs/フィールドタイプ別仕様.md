> 計算式プラグインの文書をそのまま置いたもの。項目の型ごとに計算式で取れる値の形。**印刷屋のエンジンは文字列の中の `\` を解釈しないので、`"\n"` は改行にならない（`\` と `n` の 2 文字）。改行は `NEWLINE()`。**


### フィールドタイプ別仕様 - 計算式プラグイン

このファイルでは、各フィールドタイプに応じた値の設定仕様を記述します。これにより、計算式プラグインの計算式を作成する際の精度を向上させます。

#### **文字列1行**
- **説明**: 単一行の文字列を保持します。
- **設定仕様**:  計算式の例
  - 文字列
  ```
  "ABC"
  ```
  結果: "ABC"
  - 数値
  ```
  100
  ```
  結果: "100"
  - 配列
  ```
  ARRAY("A","B","C")
  ```
  結果: "A,B,C"
  - 複数選択
  ```
  複数選択
  ```
  複数選択の値：["A","B","C"]
  結果: "A,B,C"
  - チェックボックス
  ```
  チェックボックス
  ```
  チェックボックスの値：["A","B","C"]
  結果: "A,B,C"
  - ドロップダウン
  ```
  ドロップダウン
  ```
  ドロップダウンの値："ABC"
  結果: "ABC"
  - ラジオボタン
  ```
  ラジオボタン
  ```
  ラジオボタンの値："ABC"
  結果: "ABC"
  - リンク
  ```
  リンク
  ```
  リンクの値："https://www.test.com"
  結果: "https://www.test.com"
  - 日付
  ```
  日付
  ```
  日付の値："2024-12-01"
  結果: "1732978800"
  **注意事項**
  文字列項目に日付項目をそのまま指定すると、数値としてセットされる
　日付を "YYYY-MM-DD" の書式で表示する場合は、日付をDATE_FORMAT関数で文字列に変換する必要がある
  - 日付文字列変換
  ```
  DATE_FORMAT(日付)
  ```
  日付の値："2024-12-01"
  結果: "2024-12-01"
  **注意事項**
　DATE_FORMAT関数で書式を省略すると規定値の "YYYY-MM-DD"で変換される。記述が短くわかりやすいので"YYYY-MM-DD"形式にする場合は、DATE_FORMAT(日付)のように書式を省略することを推奨する。
  - 時刻
  ```
  時刻
  ```
  時刻の値："10:30"
  結果: "10:30"
  - 日時
  ```
  日時
  ```
  日時の値："2024-12-01 10:30"
  結果: "2024-12-01 10:30"
  - ユーザー選択
  ```
  ユーザー選択
  ```
  ユーザー選択の値：[{"code":"user1","name":"name1"},{"code":"user2","name":"name2"}]
  結果: "name1, name2"
  - 組織選択
  ```
  組織選択
  ```
  組織選択の値：[{"code":"org1","name":"name1"},{"code":"org2","name":"name2"}]
  結果: "name1, name2"
  - グループ選択
  ```
  グループ選択
  ```
  グループ選択の値：[{"code":"group1","name":"name1"},{"code":"group2","name":"name2"}]
  結果: "name1, name2"

#### **文字列複数行**
- **説明**: 複数行の文字列を保持します。
- **設定仕様**:  計算式で文字列をセットすること。文字列中の"\n"で改行される。
  - リテラルの文字列
  ```
  "文字列複数行\n複数行の文字列\n改行も含む"
  ```
  - リテラルの文字列（計算式中の改行コードは計算処理時に無視される）
  ```
  "文字列複数行"&NEWLINE()&
  "複数行の文字列"&NEWLINE()&
  "改行も含む"
  ```
  計算結果："文字列複数行\n複数行の文字列\n改行も含む"
  - 関数で文字列をセット
    ARRAY関数とJOIN関数で、改行を含む文字列を作成。改行が多い文字列だと計算式が見やすくなるメリットとがある。
  ```
  JOIN(ARRAY(
    "文字列複数行",
    "複数行の文字列",
    "改行も含む"
  ),NEWLINE())
  ```
  計算結果："文字列複数行\n複数行の文字列\n改行も含む"

  - 関数で文字列をセット2
    ARRAY関数とJOIN関数で、改行を含む文字列を作成。改行が多い文字列だと計算式が見やすくなるメリットとがある。
  ```
  JOIN(ARRAY(
    "ABC",
    "日付：" & TODAY(),
    "XYZ"
  ),NEWLINE())
  ```
  計算結果："ABC\n日付：2024-12-10\nXYZ"

  ```
  ""
  ```

  ```

  ```

  ```
  -1234
  ```

  ```
  -1234.56
  ```
  - リテラルの数値を表す文字列
  ```
  "1234.56"
  ```
  - 指数表示
  ```
  "100e2"
  ```
  - 数値の演算子を使った計算
  ```
  (数値1 + 100) * 2
  ```
  - 数値を返す関数を使った計算
  ```
  ABS(-100)
  ```

#### **チェックボックス**
- **説明**: 複数の選択肢から0個以上を選択可能。
- **設定仕様**:  配列で、選択肢を保持します。例: ["A","B","C"]。選択肢以外の値を指定するとエラーになる。
  - 選択肢無し
  ```
  ARRAY()
  ```
  - 選択肢セット
  ```
  ARRAY("選択肢1", "選択肢2")
  ```
  - 他のチェックボックスの値をセット
  ```
  ARRAY(チェックボックス1)
  ```
  **注意事項**
  他のチェックボックスの値をセットするには、ARRAY 関数での指定が必要

  - 他の複数選択の値をセット
  ```
  ARRAY(複数選択1)
  ```
  **注意事項**
  他の複数選択の値をセットするには、ARRAY 関数での指定が必要


  - 選択肢以外の値を排除してセット
  ```
  LET(
    opt, ARRAY("A", "B", "C"), // 選択肢
    inp, SPLIT("A,B,D,,X", ","), // 入力値
    INTERSECT(opt, inp), // 設定値
  )
  ```

#### **日付**
- **説明**: 年月日を保持。
- **設定仕様**:　1970-01-01を 0 とした、秒換算の数値で日付の値を保持。 
  - 日付の文字列をセット
  ```
  "2024-01-01"
  ```
  - 日付を示す数値を秒換算で
  ```
  1732978800
  ```
  計算結果："2024-12-01"

  - 日付項目を指定
  ```
  日付1
  ```
  - 日付を示す値を返す関数を指定
  ```
  DATE_ADD(日付1,1,"month")
  ```
  計算結果：日付1が"2024-11-01"の場合、"2024-12-01"
  - 日付を示す値を返す関数を指定2
  ```
  DATE_FORMAT(日付1,"YYYY-MM-01")
  ```
  計算結果：日付1が"2024-12-10"の場合、"2024-12-01"

#### **時刻**
- **説明**: 時刻を保持。
- **設定仕様**:  文字列の "HH:mm" 形式で時刻を保持。"13:70","25:30" などの不正時刻をセットするとエラーになる。
  - 時刻をクリア
  ```
  ""
  ```
  - 時刻の文字列をセット
  ```
  "12:34"
  ```
  - 現在時刻をセット
  ```
  DATE_FORMAT(NOW(),"HH:mm")
  ```
  - 現在時刻をセット2
  ```
  DATE_FORMAT("TODAY","HH:mm")
  ```

#### **日時**
- **説明**: 日付と時刻を保持。
- **設定仕様**:  文字列の "YYYY-MM-DD HH:mm" 形式で日時を保持。"2024-12-10 13:70" などの不正時刻をセットするとエラーになる。
  - 日時をクリア
  ```
  ""
  ```
  - 日時の文字列をセット
  ```
  "2024-12-10T12:34:00"
  ```
  計算結果："2024-12-10 21:34"
  - 日時の文字列をセット2
  ```
  "2024-12-10 21:34"
  ```
  計算結果："2024-12-10 21:34"
  - 日時の文字列をセット3(時刻無し)
  ```
  "2024-12-10"
  ```
  計算結果："2024-12-10 00:00"
  - 日時の文字列をセット4(時刻付加)
  ```
  IF(日付1, 日付1 & " 14:10")
  ```
  計算結果：日付1が"2024-12-10"の場合、"2024-12-10 14:10"
  - 日時の数値（秒換算）をセット
  ```
  1732978800+5.5*60*60
  ```
  計算結果："2024-12-01 05:30"
  - 現在時刻+1時間をセット
  ```
  DATE_ADD("TODAY",1,"hour","YYYY-MM-DD HH:mm")
  ```
  - 現在時刻+1時間をセット2
  ```
  DATE_ADD(NOW(),1,"hour","YYYY-MM-DD HH:mm")
  ```

#### **リンク**
- **説明**: 項目設定の「入力値の種類」により、「Webサイトのアドレス」「電話」「メールアドレス」を保持。
- **設定仕様**:  
  「Webサイトのアドレス」: "http://" または "https://" で始まる文字列
  「電話」：文字列で、特に制限なし
  「メールアドレス」："@"が含まれる文字列
  - 「Webサイトのアドレス」に URL をセット
  ```
  "https://example.com"
  ```
  - 「電話」に URL をセット
  ```
  "03-0000-0000"
  ```
  - 「メールアドレス」に メールアドレスをセット
  ```
  "sample1@sample.com"
  ```

#### **ユーザー選択**
- **説明**: ユーザーを選択可能。
- **設定仕様**:  配列で複数ユーザーのユーザーコードとユーザー名を保持する。
  編集画面上のUIでユーザーを選択するとユーザー名を表示するが、[{"code":"user1"}]のようにユーザーコードのみセットすると画面上でユーザーコードを表示し、レコード保存後にユーザー名を表示する。[{"code":"user1","name":"name1"}]のようにユーザーコードとユーザー名をセットすると画面上でユーザー名を表示する。
  - ユーザー選択をクリア
  ```
  ARRAY()
  ```
  - ユーザーコードをセット
  ```
  SET_CODE("user1")
  ```
  計算結果：[{"code":"user1"}]
  - 複数のユーザーコードをセット
  ```
  SET_CODE(ARRAY("user1","user2"))
  ```
  計算結果：[{"code":"user1"},{"code":"user2"}]
  - ユーザーコードとユーザー名をセット
  ```
  UINFO("user1","setData")
  ```
  計算結果：[{"code":"user1","name":"name1"}]
  - 複数のユーザーコードとユーザー名をセット
  ```
  UINFO(ARRAY("user1","user2"),"setData")
  ```
  計算結果：[{"code":"user1","name":"name1"},{"code":"user2","name":"name2"}]
  - 他のユーザー選択項目のユーザーをセット
  ```
  SEL_CODE(ユーザー選択1,"obj")
  ```
  計算結果：[{"code":"user1","name":"name1"},{"code":"user2","name":"name2"}]
  - 他のユーザー選択項目の先頭ユーザーをセット
  ```
  SLICE(SEL_CODE(ユーザー選択1,"obj"),0,1)
  ```
  計算結果：[{"code":"user1","name":"name1"}]
  - 複数のユーザー選択項目のユーザーをセット
  ```
  DISTINCT(SEL_CODE(ユーザー選択1,"obj"),SEL_CODE(ユーザー選択2,"obj"))
  ```
  計算結果：[{"code":"user1","name":"name1"},{"code":"user2","name":"name2"},{"code":"user3","name":"name3"}]

#### **ルックアップ**
- **説明**: 他のレコードの値を参照。
- **設定仕様**:  文字列または数値で値を保持。ルックアップ項目の設定で定義されたコピー項目が更新される。セットした値が参照先レコードに無い場合、エラーになる。
  - 参照先の会社コードをセット
  ```
  "A001"
  ```
  計算結果："A001"
  - 参照先のレコード番号をセット
  ```
  100
  ```
  計算結果：100

#### **リッチエディター**
- **説明**: リッチテキスト形式の内容を保持。
- **設定仕様**:  計算式プラグインの設定先対象外の項目。プラグイン設定画面の設定先項目にリッチエディター項目は表示されません。リッチエディター項目を計算式で参照することは可能。
  - リッチエディターに設定されている文字列例
  ```
  "<div><b style=\"background-color:rgb( 255 , 0 , 0 )\">ABC</b></div><div>DDD</div>"
  ```

#### **テーブル**
- **説明**: テーブル形式で複数行を保持。配列で行単位に項目値を保持。
- **設定仕様**:  
  - テーブル行数: 1～1000 の数値を指定すると、テーブル行数を指定行数でセット。1～1000 以外の数値の場合は、なにも変更しない。指定行数がテーブル行より小さい場合は、指定行数より多いテーブル行を削除する。指定行数がテーブル行より大きい場合は、増加分のテーブル行を追加する。
    - 数値でテーブル行を指定
    ```
    10
    ```
    計算結果：テーブル行数を10行にする
    - 数値項目の値でテーブル行数を指定
    ```
    数値1
    ```
    計算結果：テーブル行数を数値1の値にする。数値1が 20 の場合は、20行にする。
  
  - 文字列のテーブルデータ（テーブルの初期データ）： テーブルの計算式で、文字列のテーブルデータを指定すると、レコード追加画面表示時にテーブルの内容を設定します。
    - テーブル初期データとして、配列をJOSON文字列化して指定
    ```
    "[{'番号':'1','区分':'A'},{'番号':'2','区分':'B'},{'番号':'3','区分':'C'},{'番号':'4','区分':'D'},{'番号':'5','区分':'E'}]"
    ```
    計算結果：レコード追加画面表示時に、指定された5行分のテーブルデータが設定される
    - テーブル初期データとして、関数の返り値の配列をJOSON文字列化して指定
    ```
    JSON_S(ARRAY_FOR(6,idx,
      DIC(
        "区分T1",IF(idx%2,"B","A"),
        "文字列T1","TEST"&(idx+1),
        "数値T1",RANDBETWEEN(10,100)*10
      )
    ))
    ```
    計算結果：レコード追加画面表示時に、指定された6行分のテーブルデータが設定される

  - オブジェクトのテーブルデータ：テーブルの計算式で、オブジェクトのテーブルデータを指定すると、計算処理時にテーブルの内容を設定します。
    - シナリオ: テーブル「テーブル」を項目「ドロップダウンT」で昇順、項目「数値T」で降順にソートします。
    ```
    TABLE_SORT(テーブル,
      TPSORT(ドロップダウンT, 数値T, 0)
    )
    ```
    計算結果:  指定した条件で並び替えられたテーブルが返されます。

    - シナリオ: テーブル「テーブル」から項目「数値T」が0より大きい行のみをフィルターし、その後「ドロップダウンT」で昇順、「数値T」で降順にソートし別テーブルにセット
    ```テーブル「ソート後テーブル」の計算式
    TABLE_SORT(テーブル,
      TPFILTER(数値T > 0),
      TPSORT(ドロップダウンT, 数値T, 0)
    )
    ```
    計算結果: 条件を満たし、ソートされたエータがソート後テーブルにセットされます。


    - シナリオ: レコード保存時に指定した条件で不要なテーブル行の自動削除を行います。
    ```テーブルの計算式
    IF(EV_INFO("mode")="success"&&更新日時,
      TABLE_SORT(テーブル,
        TPFILTER(ルックアップ)
      )
    )
    ```
    計算結果: レコード保存時に、ルックアップの値が未設定のテーブル行が削除されます。
